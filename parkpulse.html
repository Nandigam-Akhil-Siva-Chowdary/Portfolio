IoT Project

ParkPulse

Raspberry Pi, SG90 Servo, HC-SR04, RADAR, HTTP/S, UART, SPI, I2C

Real-time IoT smart parking and access control system.

ParkPulse is an IoT-based intelligent parking and access control system developed to reduce manual parking management and traffic congestion using multi-sensor fusion with radar and ultrasonic sensing.

The system integrates a cloud-based web dashboard for live slot occupancy visualization and an automated servo-driven barrier gate that locks out vehicles when the parking lot reaches maximum capacity.

Radar and ultrasonic based slot detection
Cloud dashboard for real-time occupancy
Servo barrier gate with capacity lockout

System highlights

Features

Smart Slot Detection

Detects vehicle presence using radar and ultrasonic inputs to improve parking slot accuracy.

Live Dashboard

Shows parking slot occupancy in real time through a cloud-connected web dashboard.

Automated Barrier

Controls entry with an SG90 servo gate and blocks access automatically when the lot is full.

Hardware and protocols

Components Used

Controller

Raspberry Pi used as the main controller for sensor processing, dashboard communication, and gate logic.

Sensors

HC-SR04 ultrasonic sensor and radar module used together for multi-sensor parking detection.

Communication

HTTP/S, UART, SPI, and I2C used for cloud data transfer and hardware communication.
