IoT Project

NovaMove

Smart Offline Voice Controlled Wheelchair

An assistive mobility system built for simple, reliable movement.

NovaMove is an IoT based wheelchair concept focused on offline voice control, accessible movement, and dependable embedded operation. The project combines hardware control, voice command handling, and mobility automation to support users who need hands-free navigation.

Offline voice command support
Embedded control with IoT hardware
Designed for practical assistive use

Project details

What NovaMove Includes

Core Idea

Convert spoken instructions into movement actions so the wheelchair can move without depending on continuous internet access.

Bed to Chair Conversion

Includes a conversion concept that helps transform between bed-to-chair and chair-to-bed positions for better mobility support.

Home Automation

Supports home automation control through offline voice commands, allowing users to operate connected devices without internet dependency.
